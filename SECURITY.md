# Security Policy

## Scope and intent

`gaming` is a network discovery and reachability analysis tool. It is intended
for authorized use only — against infrastructure you own or have explicit
permission to assess. Global reachability checks submit target IPs to a
third-party service (check-host.net).

## Reporting a vulnerability

If you discover a security issue in the tool itself (not in a network you
scanned), please report it privately:

- Open a [GitHub Security Advisory](https://github.com/your-org/gaming/security/advisories/new), or
- Email the maintainers rather than filing a public issue.

Please include reproduction steps and the output of `gaming --version`. We aim
to acknowledge reports within a few days.

## Supported versions

The latest released `0.x` version receives fixes. As a pre-1.0 project, older
versions are not maintained.
